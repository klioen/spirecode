# Spec: 收紧 Changes 树形视图缩进

## Requirements

1. Changes Tree 视图根节点左侧内边距保持 12px。
2. Tree 视图每深入一级，左侧内边距只增加 8px。
3. 目录节点和文件节点必须使用相同的层级缩进公式。
4. Changes 文件行不得渲染额外缩进占位；同层文件图标和目录展开图标从相同的左侧位置开始。
5. List 视图、目录折叠、diff resource id、单双击打开行为及 Git 状态标记保持不变。

## Design

- 在 `ChangesPanel.tsx` 中定义树形行基础缩进和层级步长常量，并由目录行、文件行共享缩进计算函数。
- 仅移除 Changes 文件行中的 `tree-indent` 占位；Files 面板的树形布局不在本次范围内。
- 组件测试直接断言代表性的根目录、嵌套目录和深层文件行内样式，防止后续重新引入过大的层级步长。

## Concerns

- 仅修改文件行会破坏同层目录/文件对齐，因此两类节点必须共享计算。
- 目录有展开图标而文件没有；本次按产品要求让文件图标与同层目录展开图标起点一致，而不是与目录文件夹图标对齐。
